# Architecture

```
api/selfcheck/
  providers/       github.py, gitlab.py, local.py, and the GET-only HTTP client
  engines/         claude, codex, cursor, anthropic_api, openai_api, tools.py
  subproc.py       runs an agent CLI: env scrubbing, timeout, cancel, raw log
  workspace.py     fetch-only mirror cache + chmod-read-only worktrees
  diffparse.py     unified diff -> files/hunks/lines with absolute line numbers
  prompts.py       the review prompt, depths, rules, learned decisions, contract
  service.py       sync, diff cache, runs, notes, second opinions, questions, budget
  watches.py       repository wakeups
  scheduler.py     the background loop: watched PRs and due wakeups
  settings_store.py  settings changeable from the app
  routes/          reviews, runs+notes, wakeups, settings, analytics, agent, system
web/src/           React 19 + Vite + Shiki, no UI framework, no router
branding/          the identity, generated by build.py
scripts/release/   plan.py and bump.py, used by the release workflow
```

## A review run

1. Sync metadata (a `GET`).
2. Fetch the diff — GitHub serves one; GitLab's is rebuilt from its JSON;
   a local branch's comes from `git diff`.
3. Parse it into files, hunks and lines with **absolute line numbers**, which
   is what lets a finding anchor to a line that exists.
4. A fetch-only mirror and a read-only worktree at the head commit.
5. Build the prompt: the change, the depth, repository rules, learned
   decisions, and on a re-review the previous findings and what moved.
6. Run the engine in the worktree, streaming progress over SSE.
7. Parse the JSON block, store the notes (or, for a second opinion, keep them
   on the run), record the counts and what shaped the review.

## Releases

Every pull request merged into `main` releases. `scripts/release/plan.py`
decides how much (a `release:*` label, else the title, else patch);
`scripts/release/bump.py` writes the version into `api/selfcheck/__init__.py`,
`api/pyproject.toml` and `web/package.json` and dates the changelog; the
workflow tags, publishes a GitHub release and pushes a multi-arch image to
`ghcr.io/unchained-labs/selfcheck`.
